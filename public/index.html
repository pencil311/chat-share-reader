chat-share-reader

An MCP server that reads public ChatGPT share links into structured transcripts.

POST /mcp

This is a Model Context Protocol endpoint, not a web app — it speaks JSON-RPC 2.0 over HTTP POST. Add the URL above as a custom MCP connector in your AI client and it can read shared conversations instead of telling you it can't open links.

Tools

ToolWhat it does
read_shared_chat Parses a share link into a full transcript (markdown, json, or text).
get_shared_chat_metadata Cheap preview: title, model, message count, first two messages.

Check it works

curl -X POST https://<this-host>/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

PlatformHow
ChatGPTchatgpt.com/share/… — works here
