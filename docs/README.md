"Connect it to Claude" walkthrough. Three files, in step order:

| File | Shows |
| --- | --- |
| `connectors-1-settings.png` | Settings → Connectors, with the **Add** button at the top right |
| `connectors-2-add-menu.png` | The **Add** menu open — *Browse connectors* / *Add custom connector* |

## Retaking them

Claude's settings UI changes, so these will drift. When retaking:

- Capture the panel, not the whole desktop — the surrounding window is noise.
- Keep all three in the same theme so the sequence reads as one flow.
- Blur or avoid anything account-specific: email address, workspace name, and
  any other connectors you have installed.
- Keep the filenames above. The README links to them by name, so a rename
  silently breaks the images.
